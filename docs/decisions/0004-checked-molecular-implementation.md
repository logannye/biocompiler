# Checked molecular implementation with explicit completion scope

## Context

The intent language can describe more behavior than the product-cassette compiler
can encode. Selecting a CDS for a secretion action does not encode its sensing,
control, localization, processing or response requirements. The next extension
must connect source requirements to explicit molecular structure without turning
a library declaration into evidence that a therapy works.

## Decision

Preserve the existing source language, frozen human contracts, pass manager and
independent verification boundary. Add a bounded molecular implementation profile
with three connected responsibilities:

1. Analyze the full source into typed implementation obligations and diagnostics.
   Preserve every source node and the original target, including requirements
   outside the supported construction family. Unsupported or underspecified
   behavior remains visible before and after molecular selection.
2. Select a declared, sequence-backed implementation architecture under hard
   constraints. Represent its molecular roles, relationships and host/external
   dependencies separately from demonstrated biological capabilities.
3. Derive the encoded construct, explicit processing/junction coordinates and RNA
   sequence. Independently reconstruct source, selection, plan, layout and exact
   bases from retained request authority.

The first family is one mature RNA cassette encoding a declared secreted-product
precursor. Supplied coding segments identify the targeting segment, optional
junction, mature product and terminal stop. Expected precursor/product proteins
and the intended processing boundary are independent input authority. Their
structural correspondence does not establish cleavage, trafficking, secretion,
expression magnitude or biological effect.

The existing synthetic digital mechanism profile remains separate. A digital
gate with a sequence attached is not a molecular implementation of that gate.
Target modality constrains molecular selection before construction. This RNA
family does not implement DNA transcriptional regulation or multi-molecule
delivery, and does not silently convert between those targets.

Sequence authority has explicit fixture, supplied-sequence and supplied-reference
provenance categories. A supplied reference records the caller's attribution;
it is not independently retrieved, experimentally characterized or promoted by
the compiler. Existing fixture schemas retain their original restrictions.

Partial research builds may retain unimplemented behavior while producing a
precisely scoped structural candidate. Strict implementation requests cannot
emit a payload while required behavior remains unresolved. Neither mode changes
human admission or grants empirical support. Every exported artifact retains its
completion scope and must pass fresh checks against the independent request.

## Consequences

Engineers can inspect how product-processing requirements map to molecular roles
and emitted bases, supply pinned sequence records, compare bounded alternatives,
and see exactly what a candidate leaves unresolved. A fixed library and request
reproduce the same structural result; they do not make cellular outcomes
deterministic.

Future sensing/control families must add explicit implementation rules, sequence
relationships and model/observation bindings. Quantitative execution must consume
the selected component and sequence identities. Changing those identities
invalidates dependent behavior evidence, even when a protein spelling is retained.

The local GUI remains a view of the earlier product-cassette profile until it is
deliberately extended to expose these new contracts.

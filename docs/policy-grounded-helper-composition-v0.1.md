## Provider and causal bootstrap

A helper provider retains the usual exact definition, recipient, availability
and typed capacities. Its closed helper-specific fields are `material` (the
complete helper material Model pin), `environment` and `delivery` DefinitionRefs,
`capacity_profile` = `biocompiler.policy_supplied_grounded_helper_capacity.v0.1`,
and `bootstrap` = `{profile, completion, prerequisites}`. Bootstrap profile is
`biocompiler.policy_source_independent_expression_completion.v0.1`;
`completion` is an exact earliest/latest interval and `prerequisites` is empty.
The helper provider definition equals the material capability and has original
semantic category `capability`. It must occur as an exact dependency of the
selected original implementation catalog entry. The prerequisite graph adds
`helper_environment` and `helper_delivery` edges. Missing provider bodies remain
Unknown; unsupported kinds and causal contradictions cannot mint closure.

The existing delivery `expression` interval does not specify completion. The
new explicit bootstrap premise supplies completion under source-independent
expression machinery. Require, with exact rational arithmetic:

1. Original delivery expression.latest <= helper completion.earliest.
2. Completion.latest <= helper availability.onset_min.
3. Helper availability.onset_max <= the original deployment-clock origin for source tick zero.
4. Helper onset_min + duration_min >= origin + horizon_ticks * period.
5. Every helper capacity covers the full original execution window in the supplied deployment-clock mapping and its
   guaranteed interval is contained in the helper's guaranteed interval.

The original Delivery provider must already be grounded independently of the
helper. Empty helper material/bootstrap prerequisites exclude self-support,
consumer-triggered initialization and helper-dependent expression machinery.
A positive nonzero completion fixture explicitly supplies a later deployment-clock
origin for source tick zero; a positive completion with that origin at zero must reject.
This explicit context mapping leaves source tick semantics unchanged.

## Complete handoff

The candidate starter must contain exactly **58 copied files and one canonical
manifest**: 12 source documents/examples/assets, three checked wheels, the
comparison, candidate and comparison-pinned child receipt, plus the complete
40-file researcher evidence folder. The child receipt remains
`evidence/researcher-alpha.json`; its paths resolve under `evidence` and every
peer remains at `evidence/researcher-alpha/<name>`. There are no duplicate
`verified-examples` copies.

Reconstruction binds the child receipt to the independent installed comparison
before reading its file pins. Missing, extra, redirected or changed sidecars,
mutation files, projects, paired archives or source documents fail. Self-rehashing
an altered child or starter manifest does not replace its independent authority.
The starter keeps `installed_candidate`, pending overall/actual-main acceptance,
unassessed empirical behavior and unqualified real-project status.

## Validation and use

Use the same authenticated prepare/check protocol described in
[the researcher-alpha audit](release-audit-researcher-alpha-v1.md), selecting this
new profile for both commands. Complete-source preparation still requires a
clean, fully materialized source checkout at the independently authenticated
head/tree. A sparse source checkout cannot satisfy that census. The audit-tool
checkout itself can stay sparse. There is no fallback to partial source or
historical authority when complete source or retained run evidence is absent.

Run the focused new pure tests with the frozen source checkout specified:

```sh
BIOCOMPILER_AUTHORING_SOURCE_ROOT=/absolute/typed-source \
  python -B -m unittest tests.test_release_audit_authoring
```

Run historical researcher checks in separate processes using
`BIOCOMPILER_RESEARCHER_SOURCE_ROOT` and their historical source. The tests forbid
native execution and network calls; synthetic handoff bytes exercise audit
boundaries and do not constitute hosted evidence. Run both supported Python
versions. A passing test or prepared plan does not establish a completed release
audit. Exact-head integration, parent/tree proof, fresh complete actual-main
validation and owner acceptance remain separate obligations. Artificial supplied
contracts provide no empirical evidence, and this profile expands no lowerer.

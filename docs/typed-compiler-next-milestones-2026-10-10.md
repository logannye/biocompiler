## Milestone 1: bounded implementation scope

The first path is the existing finite-machine component-material family. This
increment strengthens representation and access to an already defined semantic
profile; it does not silently combine every installed feature or enlarge the
supported biological claims.

Required exits:

1. The selected producer path consumes resolved typed terms rather than
   rediscovering executable expression meaning through string-tagged JSON.
   Original wire input and occurrence metadata remain independent authority.
2. Pass interfaces distinguish decoded, admitted, proposed and independently
   checked values. Producer/checker and source/candidate execution separation
   remain intact; shared types do not make shared semantic algorithms independent.
3. A typed immutable build specification integrates this profile with
   `ResearchProject`: compile with Core, export with independent Verify, and
   reopen/reverify the exact paired FASTA and manifest outside the checkout.
   Supplied component/model/material authority stays explicit and complete.
4. At least two existing finite-machine shapes exercise the same path. Exact
   legacy outputs and source lineage are preserved; altered authority, private
   state/reference errors, wrong profiles/roles and malformed data reject.
5. Focused local pure-Python/static/type checks pass. One coherent hosted native
   development batch then validates the changed source. Integration and fresh
   actual-main acceptance remain separate required gates for a later merge;
   local checks alone cannot mark this milestone validated.

## Public biological evidence as a design input

Use primary public mRNA and programmed CAR-T sources where they supply reliable
material or behavioral facts. Continue the existing source qualification work;
do not substitute a citation, a protein/CDS, or a plasmid for a complete delivered
RNA specification. Preserve source version, exact available material identity,
experimental context, observation meaning, access and reuse limitations, and
every missing field. Do not invent UTRs, chemistry, tails or dynamic contracts.

Extract concrete compiler obligations such as subject identity, ordered versus
simultaneous recognition, effect initiation versus persistence, and the scope
of measured observations. A software counterexample can exercise those
obligations without being relabeled as a reproduced biological experiment.
The bounded [public-source design review](typed-path-public-evidence-2026-10-10.md)
records inspected primary sources, seven proposed acceptance criteria, and
the missing complete-material and model-to-assay joins.
Sequence fidelity, model-conditional translation, empirical function and human
therapeutic suitability remain separate claims. An inaccessible or incomplete
source must not delay independently achievable typed compiler work.

# Semantic regression matrix v0.1

This matrix checks the abstract behavioral execution contract against supplied
piecewise-constant observations. Its expected timelines are hand-written from
[Behavior semantics](behavior-semantics-v0.1.md). They are not generated by the
evaluator, a synthesis candidate or a second implementation of its timer logic.
Passing these tests does not establish biological realizability or enlarge the
supported synthesis profile.

The matrix adds cross-operator cases to the existing focused execution tests.
In `tests/test_semantic_matrix.py`, four table-driven test groups execute 25
scenarios. The observable projection records local and contact-bound active
requests, pulse start/expiry times, report reactions and settled memory values.
It removes only repeated frames with no observable state change or reaction.
Therefore an extra polling frame is harmless, while a shifted deadline, an extra
reaction or a changed contact binding fails the oracle.

## Expected-timeline matrix

| Family | Scenarios | Distinction established |
| --- | ---: | --- |
| Contact dwell, two pulse scopes and cell memory | 8 | Same-object evidence, episodes, onset and distinct local/contact lifetimes |
| Ordered events with a recent-history guard | 4 | Strict temporal order, inclusive order window and exclusive recency expiry |
| Producer and consumer memory | 5 | Causal settlement, refresh/reset precedence and independent latch lifetimes |
| Condition-triggered and event-triggered pulses | 8 | Four input timelines applied to both modes; latest onset controls expiry |

The contact controller requires A and B on one object continuously for two
seconds. Qualification starts a three-second local pulse, a three-second
contact-bound pulse and three-second cell memory. Its cases distinguish:

- A and B on the same object from A and B split between objects.
- A split observation becoming a qualifying same-object observation later.
- Transient qualification and a false input exactly at the dwell deadline.
- Switching object identity before the deadline, which starts a fresh dwell.
- Contact disappearance after qualification, which cancels the bound pulse while
  local pulse and cell memory retain their own deadlines.
- The same identifier reappearing after disappearance, which starts a new episode
  and cannot reuse the previous dwell interval.

The ordered-event controller requires an A onset strictly before a B onset within
two seconds. A separate ongoing output requires B while A is present or recent.
The cases cover simultaneous A/B onsets, B exactly at the inclusive order-window
boundary, B exactly at the exclusive recent-history endpoint, and two B onsets
justified by the same non-consuming A event. Several expiry times fall between
external snapshots; they must still produce settled output changes.

The producer memory lasts two seconds, with level-sensitive reset. Its consumer
memory lasts one second and can set only when the settled producer and an external
gate are true. The cases cover:

- A gate arriving exactly at producer expiry, which must not latch the consumer.
- A setting onset refreshing the producer at old expiry without an artificial
  producer false/true event.
- Reset coinciding with setting, expiry and gate arrival; reset dominates.
- Releasing reset while setting remains true, followed by a genuinely new onset.
- Resetting a producer after the consumer has already latched; the independent
  consumer retains its own deadline.

The pulse matrix uses two-second pulses in both condition and event mode. Literal
expected timelines distinguish continuous truth, retriggering before expiry,
retriggering exactly at expiry and retriggering after a real inactive interval.
One current request replaces the prior deadline; pulses do not stack.

All matrix times are integers or exactly representable half seconds. Expected
observations use exact equality rather than numerical tolerances. These choices
isolate the stated discrete-time semantics from floating-point approximation.

## Metamorphic invariants and their preconditions

`tests/test_semantic_metamorphic.py` adds five invariant groups. The transformation
preconditions are part of each claim; they are not unrestricted graph rewrites.

| Transformation | Required precondition | Compared observations |
| --- | --- | --- |
| Consistent contact-object renaming | A bijection applies to every occurrence in every episode; observations and timing remain unchanged | Map bound actions and event identities back through the inverse bijection; compare complete semantic frames |
| Intent, Behavior IR and typed history round trips | Strict versioned parsing retains every field; restore `SignalSample` types explicitly | Exact graph identities, lowering correspondence and complete execution records including source lineage |
| Reordering independent declarations | Three branches share no state writes, memory controls or output feedback; signal bindings are remapped by declared names | Named actions, pulse deadlines, reactions, events, finite states and memories across all six permutations |
| Inserting unchanged snapshots | Every insertion copies the complete current external snapshot; contact identities and the explicit horizon remain fixed | Full events/reactions and every observable deadline, after removing stutter frames |
| Reordering snapshot mappings | The same atomic signal/contact mappings and values are retained | All semantic frames; mapping iteration order cannot become execution priority |

Contact-renaming tests deliberately reverse lexical object order. The controller
combines ordered events, contact dwell, pulses, memory and contact disappearance,
so preserving final counts alone would be insufficient. Each bound request and
event must retain its corresponding object identity, timing and provenance.

Declaration-order tests intentionally permit artifact fingerprints and node IDs
to change. They compare explicit semantic names rather than assuming graph IDs are
stable across edits. They also assert that named latch/report outputs occur, so an
empty trace cannot satisfy the invariant vacuously. This transformation is not
valid for branches that write conflicting values to shared state.

Snapshot densification includes both quarter-second polls and exact internal
deadlines. Stutter normalization removes only frames with unchanged persistent
observations and no events or reactions. It does not erase a transient output,
deadline change, repeated reaction or new contact event. Splitting a simultaneous
snapshot into different times, merging object identities, extending the horizon,
or inventing prehistory is outside this invariant.

These regression layers complement independent realization checks, artifact
freshness checks and exact-CDS mutation tests. They preserve the evaluator as an
explicit behavioral oracle without treating an abstract requested action as an
observed molecular effect.

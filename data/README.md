# Data and registry policy

No biological parts, model parameters, or therapeutic sequences are included in this scaffold.

Future fixture records must identify their source, version, applicable cellular context, assumptions, and evidence. Keep synthetic software-test fixtures distinguishable from characterized biological components. Large datasets and generated artifacts belong outside Git with explicit provenance references.

The first planned biological fixtures are the independently curated FAP-CAR coding DNA, coding RNA and protein reference records described in the [benchmark curation plan](../docs/reference-benchmarks.md). These remain future inputs; no sequence records are added by the roadmap. Keep small reviewed reference inputs separate from generated build outputs, pin source and normalized-content identities, and record each artifact's exact scope and unresolved features.
